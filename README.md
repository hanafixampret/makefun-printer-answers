Entry for the [make.fun bounty](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907): one line, 1 to 240 characters, as the office printer's comeback to the jams, the error codes and the thumps.

## Entry

> Error 0xE3: paper jam. I did not jam — you fed me a stapled page, thumped me twice, then blamed the blinking light. The blinking light is me.

The printer speaks in the first person: weary, literal, faintly passive-aggressive. It denies the jam, blames the human (stapled page, two thumps), and lands the twist in the last clause — the blinking light the human keeps blaming *is* the printer itself.

## Run

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (validated: 1–240 characters, single line).
